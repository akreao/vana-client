- Party rows for mods (ours, 2026-11-25): `ui.native.party_rows()` gives where each member's row of the modern
  party and alliance windows was drawn ({panel, slot, name, x, y, w, h} in window pixels, a mod's scale of the
  window included), so a mod can put a mark beside a member's row; empty in the classic UI. First used by the
  `forever` branch's XIFO HC Icons (hardcore shields beside the party list).
