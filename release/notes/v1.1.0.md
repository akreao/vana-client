First release from akreao/vana-client. It covers everything merged since upstream 1.0.2 (lenonk `fce11ce`), including two later upstream merges.

**Updating from 1.0.2:** a 1.0.2 client looks for updates at lenonk/vana-client, so it will not offer this release. Download it from this page once; from 1.1.0 on, the client updates itself from akreao/vana-client and only installs releases signed with the release key.

## Security

- **Signed updates.** The updater installs only releases whose assets carry a valid Ed25519 signature by the release key built into the client, and checks a `.sha256` when one is published. Unsigned or badly signed releases are refused. Updates now come from akreao/vana-client, and a pre-release sorts before its release. (#73, #75, #89)
- **Server certificates are pinned.** Each server's TLS certificate is remembered on first use, or can be pinned to a known fingerprint with `vana-client trust-server HOST [--port P] [--fingerprint F]`. The handshake signature is now checked against the certificate. (#76, #86)
- **Patcher hardening.** Manifest paths that would leave the install folder are refused, and game code files (`.exe`, `.dll`) are written only when their SHA-256 is on a signed list of pinned hashes. (#91, #102)
- **Lua mods.** `/lua` runs only when the player typed it; injected packets must fit their size field; string patterns keep to the 100 ms budget; `mods.call` skips a suspended mod; `wait_until` has a budget; absolute `require` paths and links inside mod folders are refused. (#58, #92, #93, #94, #95)
- **Crash and hang hardening against bad server data.** Server-sent character names stay out of file paths; short PlayOnline session-key blocks and short lobby replies are errors instead of panics; the server can no longer make the client allocate without limit; an unreadable map datagram is dropped instead of the connection; malformed DAT files return errors; a message that jumps back into a loop is stopped. (#71, #72, #90, #96, #97, #98, #99)

## Gameplay and display

- **Movement and camera as retail** (upstream merge): eased facing, mouse wheel zooms the field of view. (#103)
- **Cutscenes:** event actors no longer shake between script steps; login events start on a black screen; the target, focus and location panels hide during events in the modern UI. Every event script op is now implemented except 0x97 cloth wind (map marker clears, game clock, actor schedulers and motions, weather blends, Mog House party members, Fishing Ranking, the Key Items window, music restart, player height). (#39–#56, #100, #101)
- **Graphics:** GPU-made mipmaps are no longer black on the GL backend. (#85)
- **Retail fixes:** chat window bottom edge no longer shakes as it shrinks; temporary items list first; main menu sub-menus open on the side their arrow points; long target names stay out from under the Commands title; item info no longer jumps for a frame; quantity and gil windows work by mouse; the busy strip shows while a PlayOnline message is sent; the Help Desk reply mark. (#16, #19, #21, #22, #23, #25, #37, #38)
- **Auto-translate** Tab completion in the macro and comment editors. (#32)

## Modern UI

Command palette (Ctrl+Space), focus and last target (`<ft>`, `<lt>`), right-click menus, double-click default actions, storage drag and drop, action registry with reasons a row is greyed, pending-action feedback, favourites, per-mode presets (Exploration, Combat, Management), panel layouts per display, Ctrl+click to move, and the link11, Play Time and Region Info windows. (#4–#10, #12, #14, #15, #20, #27)

## Gamepad

Gamepad support on retail's own pad path with the official layout, an on-screen keyboard, round stick dead zone, LB/RB tab switching, a ground-position cursor and d-pad steps in target prompts. (#2, #3, #18, #26, #33, #36, #79)

## Lua mods

Lua mod support from upstream. (#57)

## Build and tooling

CI builds, lints and tests on Linux and Windows (with stable WARP for the Windows GPU tests); clippy clean; PipeWire audio is an optional default feature; recorded-state suggestion tests. (#11, #74, #77, #78, #104)
